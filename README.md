# PancakeSwap Prediction Bot

Simple automated bot for PancakeSwap Prediction on BNB Chain.

## Features

* Monitor prediction rounds
* Bull / Bear signals
* Automatic bet execution
* Configurable bet amount
* Transaction logging

## Setup

```bash
npm install
```

Create `.env`:

```env
PRIVATE_KEY=your_private_key
RPC_URL=your_rpc_url
BET_AMOUNT=0.01
```

Run:

```bash
npm start
```
